Welcome to Pandas Data Wrangling Exercises — Handwritten Solutions! 📊

This repository contains structured solutions to canonical Pandas exercises, focusing on practical data transformation, aggregation, and cleanup pipelines.

From multi-dataset relational merges to hierarchical multi-indexes and time series resampling, these exercises build real-world confidence in transforming raw data into analysis-ready formats.

The emphasis is on method-chaining readability, defensive indexing, avoiding chained assignments, and minimizing unnecessary memory overhead.

💡 How to Approach These Puzzles

The objective is to master vector operations and defensive data engineering in Pandas:

  1. Never iterate with loops. Avoid for loops and row-by-row iteration. Use vectorized column operations or NumPy backends.
  2. Use explicit indexers. Always specify .loc or .iloc when modifying slices to prevent SettingWithCopyWarning.
  3. Embrace method chaining. Write clear, readable multi-step transformations wrapped in parentheses.
  4. Check column data types early. Convert strings to categoricals or datetimes to save memory and ensure numeric math works correctly.

The goal is clean, performant data pipeline construction that scales with large datasets.
