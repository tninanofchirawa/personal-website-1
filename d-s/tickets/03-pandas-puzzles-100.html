Welcome to 100 Pandas Puzzles — Handwritten Solutions! 🧩

Inspired by the canonical repository by ajcr, this collection tackles 100 test-driven puzzles covering subtle corner cases, string transformations, grouping heuristics, and rolling calculations.

Each puzzle tests precision thinking: how to achieve exact data frame shapes and assertions using idiomatic Pandas syntax.

Solutions prioritize concise, functional idioms that leverage optimized C/Cython execution paths under the hood.

💡 How to Approach These Puzzles

Solve with test-driven precision:

  1. Read the assertion first. Understand what exact types and indices the test case expects.
  2. Check for built-in methods. Pandas almost always has a specialized vectorized method for common tasks (e.g. clip(), cumsum(), explode()).
  3. Avoid intermediate mutable side-effects. Treat DataFrames as immutable where possible for predictable test passes.

The goal is intuitive mastery over data structures that underpins real machine learning engineering.
